# وسيلة

موقع صفحة واحدة يساعد مريض مش قادر يتكلم ولا يتحرك إنه يقول اللي هو عايزه:
مربعات كبيرة فيها أيقونة + رقم + كلمة، واللي ماسك التليفون بيدوس لما المريض يشاور،
وبعدها شاشة تأكيد «أيوه / مش قصدي». **بدون صوت — كله بصري.**

- 📄 الخطة والقرارات: [docs/PLAN.md](docs/PLAN.md)
- 🖼️ رسم الشاشات: [docs/wireframe.png](docs/wireframe.png)
- 🌐 الموقع نفسه: [index.html](index.html) (اشتغل من أي سيرفر، أو ارفعه على Cloudflare Pages)

## إزاي تستخدمه معاه (٤ خطوات)
1. امسك التليفون قدامه على مسافة يشوفها كويس.
2. اقرا له المربعات بصوتك: واحد، اتنين، تلاتة، أربعة.
3. أول ما يشاور على حاجة — دوس على مربعها.
4. اسأله «هو ده؟» → **أيوه كده** أو **مش قصدي**.

**علامة «تمريض»** معناها: اسأل التمريض الأول قبل الأكل أو الشرب.

## الصور
كل خيار أو قسم ممكن يكون له **صورة** بدل الأيقونة — من الجهاز مباشرة أو من مجلد [`images/`](images/README.md).

- كل الصيغ: `jpg · jpeg · png · webp · gif · svg · avif · bmp · ico · heic · heif · tif · tiff · apng`
- الصور الكبيرة بتتصغّر تلقائيًا (أقصى ضلع 900px + ضغط) فالتطبيق بيفضل سريع على تليفون قديم.
- `SVG` و `GIF` بيتسابوا زي ما هم (مفيش فقدان للأنيميشن أو الوضوح).
- لو صيغة مش بتتعرض في المتصفح، بترجع الأيقونة تلقائيًا — مفيش مربع فاضي أبدًا.
- الصور اللي بترفعها من الجهاز بتتحفظ **جوّه** `data.js` (فبيبقى أكبر)؛ ولو عايزه خفيف حط الصور في `images/` واستخدم «مسار صورة».

## إزاي تضيف قسم في ٥ دقايق
1. `؟ مساعدة` ← **وضع الأسرة**.
2. `+ قسم جديد` → اكتب الاسم، ارفع **صورة** أو اختار أيقونة، (اختياري) علّم «محتاج تمريض».
3. جوّه القسم: `+ خيار` لكل حاجة تحته (وينفع خيار جوّه خيار).
4. `تنزيل data.js` → ارفع الملف مكانه في الريبو → كل الأجهزة تتحدث.

## تشغيل محلي
```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

## قاعدة واحدة مهمة
**سؤال واحد في اليوم** — أي إضافة جديدة لازم تجاوب على سؤال: «هل دي هتفرق معاه بكرة؟»
لو لأ، متضفهاش.

## الخصوصية
مفيش أسماء ولا صور ولا تشخيص، مفيش سيرفر ولا تتبّع، والصفحة `noindex`.
