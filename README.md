# وسيلة

موقع صفحة واحدة يساعد مريض مش قادر يتكلم ولا يتحرك إنه يقول اللي هو عايزه:
٤ مربعات ضخمة، أيقونة + رقم + كلمة، واللي ماسك التليفون يدوس لما المريض يشاور،
وبعدها شاشة تأكيد وصوت يقول الاختيار.
