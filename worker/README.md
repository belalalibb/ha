# سيرفر المزامنة — Cloudflare Worker + KV

الملف `worker.js` ده هو السيرفر اللي بيخلي تعديلات الأسرة تظهر على كل التليفونات.
**مجاني ١٠٠٪** وبيشتغل على نفس حساب Cloudflare اللي نشرت عليه الموقع.

## إيه اللي بيعمله
- بيخزّن نسخة الأقسام لكل «كود عيلة» (٦ حروف).
- بيرجّع أحدث نسخة لأي تليفون بيسأل.
- بيحتفظ بآخر **١٠ نسخ** عشان زرار «رجوع خطوة».
- مفيش أسماء ولا حسابات ولا تتبّع — مجرد صندوق بيانات بالمفتاح.

## الإعداد (٥ دقايق — مرة واحدة)

1. افتح <https://dash.cloudflare.com> ← **Workers & Pages** ← **Create** ← **Worker**.
2. سمّيه مثلًا `wasila-sync` ← **Deploy**.
3. دوس **Edit code** ← امسح اللي موجود ← الصق محتوى `worker.js` من الملف ده ← **Deploy**.
4. ارجع للـ Worker ← تبويب **Settings** ← **Bindings** ← **Add** ← **KV namespace**:
   - Variable name: **`WASILA`**  ← بالحرف الكبير، مهم جدًا
   - KV namespace: **Create new** ← سمّيه `wasila-data` ← اختار **Save**
5. انسخ رابط الـ Worker (شكله: `https://wasila-sync.اسمك.workers.dev`).
6. جرّبه في المتصفح:
   ```
   https://wasila-sync.اسمك.workers.dev/?f=test1234
   ```
   لازم يرجّع: `{"empty":true}`

## الربط بالتطبيق

فيه طريقتين:

### أ) الأسهل (لكل التليفونات)
حط الرابط في `data.js`:
```js
meta: { ..., sync: 'https://wasila-sync.اسمك.workers.dev' }
```
وبعدها أي تليفون بيفتح الموقع بيكتب **كود العيلة بس** ويشغّل.

### ب) لينك جاهز (أسرع للأهل)
من التطبيق: `؟ مساعدة` ← **وضع الأسرة** ← **نسخ لينك الإعداد** ← ابعته واتساب.
أي حد يدوس عليه → التطبيق يفتح مظبوط لوحده (كود + سيرفر) — من غير أي كتابة.

## ملاحظات
- **الكود مش كلمة سر**: عشوائي ٦ حروف، كفاية لمنع العبث العابر. اللي عنده الكود يقدر يقرا/يعدّل.
- حدوده المجانية: ١٠٠ ألف قراءة و١٠٠٠ كتابة يوميًا — استخدام عيلة واحدة أقل من ١٪ منها.
- عايز تمسح كل حاجة؟ KV ← `wasila-data` ← امسح المفاتيح.
- **نسخة احتياطية**: من التطبيق ← «تنزيل data.js» بينزّل آخر نسخة عندك كملف.
