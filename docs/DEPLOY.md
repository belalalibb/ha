**اعمل واحدة من التانيين:**

- أو وقت إعداد الاستضافة اختار الفرع `arena/93763b87-ha` كـ Production branch.

## 1) Cloudflare Pages (الطريقة المرشّحة)

### أ) الحساب
1. افتح <https://dash.cloudflare.com/sign-up> — سجّل بإيميلك (مجاني، **مفيش كارت ائتمان**).

### ب) ربط GitHub
2. من القائمة الجانبية: **Workers & Pages**.
3. زرار **Create** ← تبويب **Pages** ← **Connect to Git**.
4. دوس **Connect GitHub** ← **Authorize** ← اختار **Only select repositories** ← حدّد `belalalibb/ha` ← Install.
5. رجع لك Cloudflare → اختار الريبو → **Begin setup**.

### ج) إعدادات البناء (مهمة)
| الخانة | اكتب فيها |
|---|---|
| Project name | اسم قصير وغريب شوية (مثال: `wasila-7k3`) — ده اللي هيبقى في الرابط |
| Production branch | `main` (أو `arena/93763b87-ha`) |
| Framework preset | **None** |
| Build command | **سيبه فاضي** |
| Build output directory | `/` |
| Environment variables | مفيش |

6. **Save and Deploy** → استنى ~٣٠ ثانية → هيظهر لك:
   ```
   https://اسم-المشروع.pages.dev
   ```
7. جرّب اللينك من الموبايل. خلاص كده — ده الرابط النهائي.

### د) تخصيصات اختيارية (كلها مجانية)
- **تغيير الاسم:** Settings ← Project name.
- **دومين خاص** (لو عندك دومين مدفوع): Custom domains ← Set up a domain.
- **منع الأرشفة:** متعمّل أصلاً (`noindex` في الصفحة).

## 2) GitHub Pages (الاحتياطي — دقيقتين)

> شرط: الريبو يكون **Public** (هو كده أصلاً).

1. افتح الريبو: <https://github.com/belalalibb/ha>
2. **Settings** ← من القائمة الشمال **Pages**.
3. تحت **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main** · folder: **/ (root)**
4. **Save** → استنى ١–٢ دقيقة → الرابط:
   ```
   https://belalalibb.github.io/ha/
   ```
5. لو ظهر خطأ 404: اتأكد إن الملفات في **جذر** الريبو (مش جوّه فولدر)، وإن `index.html` موجود.

> الكود بيشتغل تحت مسار فرعي (`/ha/`) عادي — كل المسارات نسبية.

## 3) تثبيته على التليفون (PWA — زي تطبيق بالظبط)

### أندرويد (Chrome)
1. افتح الرابط.
2. منيو **⋮** ← **إضافة إلى الشاشة الرئيسية** (أو **تثبيت التطبيق**).
3. هتلاقي أيقونة سودة في الشاشة، بتفتح **ملء الشاشة** بدون شريط عنوان.

### آيفون (Safari — لازم Safari مش Chrome)
1. افتح الرابط في **Safari**.
2. زرار **مشاركة** ⬆️ ← **إضافة إلى الشاشة الرئيسية** ← Add.

> بعد التثبيت: الشاشة مبتقفلش لوحدها (Wake Lock) وبتشتغل من غير نت بعد أول فتح.

## 5) تعديل الأقسام بعد الرفع (من الموبايل، من غير كمبيوتر)

### الطريقة السريعة (على نفس التليفون بس)
`؟ مساعدة` ← **وضع الأسرة** ← عدّل ← **حفظ**.
التعديل بيتحفظ في المتصفح على التليفون ده بس.

### الطريقة اللي تظهر على **كل الأجهزة**
1. في وضع الأسرة: **تنزيل data.js**.
2. افتح GitHub من الموبايل ← ملف `data.js` ← أيقونة القلم ✏️.
3. امسح كل المحتوى → الصق اللي نسخته ← **Commit changes**.
4. استنى ~٢٠ ثانية (Cloudflare) أو ~دقيقة (GitHub Pages) → كل الأجهزة اتحدثت.
5. على تليفونك: `؟ مساعدة` ← **تحديث النسخة**.

> بديل أخف: حطّ الصور في مجلد `images/` على GitHub واستخدم «مسار صورة» بدل رفعها — `data.js` يفضل صغير.

## 6) المزامنة بين التليفونات (خطوة واحدة إضافية — مجانية)

من غيرها: كل تليفون بيحتفظ بتعديلاته لوحده. معاها: أي تعديل بيظهر على **كل** التليفونات
في ثواني، ومن غير أي زرار على الأهل.

### أ) اعمل السيرفر (٥ دقايق — مرة واحدة)
التفاصيل الكاملة في [`worker/README.md`](../worker/README.md). باختصار:
1. Cloudflare ← **Workers & Pages** ← **Create** ← **Worker** ← سمّيه `wasila-sync` ← **Deploy**
2. **Edit code** ← الصق محتوى [`worker/worker.js`](../worker/worker.js) ← **Deploy**
3. **Settings** ← **Bindings** ← **Add** ← **KV namespace** ← Variable name: **`WASILA`** ← Create `wasila-data` ← Save
4. انسخ الرابط: `https://wasila-sync.اسمك.workers.dev`
5. جرّبه: `…?f=test1234` → لازم يرجّع `{"empty":true}`

### ب) اربطه بالتطبيق
- **الأسهل:** حط الرابط في `data.js`:
  ```js
  meta: { ..., sync: 'https://wasila-sync.اسمك.workers.dev' }
  ```
- **أو** من التطبيق: `؟ مساعدة` ← **وضع الأسرة** ← الصق الرابط + اكتب كود عيلة (أو دوس «كود جديد») ← **تشغيل المزامنة**.

### ج) وزّع على التليفونات
دوس **«نسخ لينك الإعداد»** ← ابعت اللينك واتساب. أي حد يدوس عليه، التطبيق بيفتح
مظبوط لوحده (السيرفر + الكود) — **من غير أي كتابة**.

### د) بعد كده
- أي تعديل من أي تليفون → يظهر عند الباقي خلال ~٢٥ ثانية (أو فورًا لما يفتحوا التطبيق).
- **«رجوع خطوة»** في وضع الأسرة → يرجّع آخر نسخة قبل آخر تعديل (آخر ١٠ نسخ محفوظة).
- النت قطع؟ التطبيق بيكمل شغله عادي، ويزامن أول ما يرجع — ونقطة حمرا صغيرة على `؟` لو فيه تعديل لسه مطلّع.

> ⚠️ كود العيلة **مش كلمة سر** — عشوائي ٦ حروف يكفي لمنع العبث العابر. متحطّش فيه بيانات حساسة.

## 7) QR وكارت السرير

1. بعد ما يبقى عندك الرابط، اعمله QR من أي موقع مجاني (مثل `qr.io` أو `qr-code-generator.com`).
2. اطبعه وعلّقه جنب السرير مع **الكارت الورقي** (خطة البديل لو التليفون فصل).
3. والصق نفس اللينك في جروب الواتساب العائلي.

> أقدر أعملك صورة QR جاهزة للطباعة — ابعتلي الرابط النهائي بس.

## 8) الخصوصية (مهم)

- الريبو **عام** حاليًا → أي حد يشوف الملفات (مفيش أسماء ولا صور شخصية ولا تشخيص، فمفيش مشكلة، بس اعرف).
- لو عايزه **مقفول**: Settings ← General ← Danger Zone ← **Change visibility** ← Private.
  - بعدها **GitHub Pages هيقف** (محتاج خطة مدفوعة) → استخدم **Cloudflare Pages** لوحده.
- المشروع فيه `noindex` → مش هيظهر في جوجل.
- مفيش تتبّع ولا سيرفر ولا قاعدة بيانات — كله في المتصفح.

## 9) مشاكل شائعة وحلولها

| المشكلة | السبب | الحل |
|---|---|---|
| الصفحة فاضية أو مكتوب فيها `# ha` | الفرع غلط أو Build output directory مش `/` | راجع الفرع، وخلّي output = `/` |
| 404 على `app.js` | المشروع مش في جذر الريبو | انقل الملفات للجذر |
| التعديل مش ظاهر | كاش / Service Worker قديم | `؟ مساعدة` ← **تحديث النسخة** |
| الصور مش ظاهرة على تليفون تاني | الصورة متخزنة محليًا بس | شغّل المزامنة (بترفع الصور كمان)، أو استخدم `images/` |
| «مش قادر يوصل للسيرفر» | رابط الـ Worker غلط أو الـ KV مش مربوط | راجع خطوة **WASILA** في `worker/README.md` |
| كل تليفون شايف حاجة مختلفة | كود العيلة مختلف | وضع الأسرة ← نفس الكود في كل التليفونات (أو ابعت لينك الإعداد) |
| «الصفحة مش آمنة» أو الـ PWA مش بيتثبت | لازم HTTPS | Cloudflare/GitHub بيوفروه تلقائي — اتأكد إنك بتفتح `https://` |
| الأيقونة ظهرت بدل الصورة | صيغة مش بتتعرض على المتصفح (HEIC مثلاً) | استخدم JPG/PNG/WebP |
| «مساحة التخزين اتملت» | صور كتير جوّه `data.js` | امسح صورة أو اتنين، أو استخدم مسار `images/` |
